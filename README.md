# 💼 Job Search & Application Tracker

A responsive web application built using **HTML, CSS, and JavaScript** to help job seekers organize, track, and manage their job applications in one place.

The dashboard provides an overview of job applications, interview progress, offers, and rejected applications, making the job search process easier to manage.

## 🚀 Features

- 📊 Dashboard with application statistics
- ➕ Add new job applications
- ✏️ Edit application details
- 🗑️ Delete applications
- 🔍 Search by company name, job role, or location
- 🔽 Filter applications by status
- 📅 Sort applications by date
- 🏷️ Status tracking (Applied, Interview, Offer, Rejected)
- 💾 Save application data using LocalStorage
- 📱 Responsive design for different screen sizes
- 📝 Add notes to job applications
- 🔗 Store job posting links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- LocalStorage
- Responsive Web Design

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Job-Search-Application-Tracker.git
   ```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

6. Start tracking your job applications.

## 💡 How It Works

- Add company and job details through the application form.
- Select the current application status.
- Search and filter your applications.
- Update application details whenever needed.
- Application data is stored in the browser using LocalStorage, so it remains available after refreshing the page in the same browser.

## 🎯 Project Objective

The objective of this project is to develop a simple and interactive job management tool that helps job seekers organize their applications, monitor recruitment progress, and keep track of career opportunities efficiently.
